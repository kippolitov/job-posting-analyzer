# Eval runs

Raw `--out` JSON from `npm run eval:postings -- --configs=… --out=…` lands here.
PR1 commits `pr1.json`, which the tables in [eval-models.md](../eval-models.md)
are built from. Later PRs add their own runs (`pr2.json`, `pr3.json`, `pr3-premium-none.json`) next to it.

The files are machine output. Don't hand-edit them; re-run the harness instead.
